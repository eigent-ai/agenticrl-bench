  <h1>Quarterly Product Update</h1>
   
  <p>We are excited to announce several improvements to our platform
  that have been rolled out over the past quarter. These changes reflect
  feedback from our user community and align with our roadmap goals.</p>	 



  <h2>New Features</h2>

  <ul> 	
    <li>Dashboard redesign with customizable widgets</li>
    <li>Export functionality now supports CSV and JSON formats</li>  
    <li>Role-based access control for team workspaces</li>
    <li>Real-time collaboration on shared documents</li>
  </ul>

	


  <h3>Dashboard Improvements</h3>

  <p>The new dashboard allows users to drag and drop widgets to create 
  a personalized view of their most important metrics. Each widget can
  be resized and configured independently.</p>


  	

  <h3>Export Enhancements</h3>

  <p>Users can now export data in multiple formats directly from any
  report view. The export dialog includes options for date range 
  filtering and column selection.</p>




  <h2>Bug Fixes</h2>

  <p>Several critical bugs were addressed in this release:</p>

  <ul>	
    <li>Fixed memory leak in long-running report generation</li>
    <li>Resolved timezone offset errors in scheduled reports</li>
    <li>Corrected pagination issues on the user management page</li>
    <li>Fixed file upload timeout on large datasets</li>
  </ul> 




  <h2>Performance</h2>  

  <p>Backend response times have improved by an average of 34% across
  all API endpoints. Database query optimization and caching layers
  were the primary contributors to these gains.</p>
	 
  <table>
    <tr><th>Endpoint</th><th>Before (ms)</th><th>After (ms)</th></tr>
    <tr><td>/api/reports</td><td>850</td><td>520</td></tr>
    <tr><td>/api/users</td><td>340</td><td>210</td></tr>
    <tr><td>/api/export</td><td>1200</td><td>780</td></tr> 
  </table>


  <h2>Known Issues</h2>

  <p>There are a few remaining issues we are tracking:</p>
  <ul>
    <li>Safari users may experience rendering delays on the dashboard</li>
    <li>PDF exports occasionally truncate long table rows</li>
  </ul>
