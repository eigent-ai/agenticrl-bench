Dual Monitor Workstation Setup Notes
=====================================

Hardware Configuration
----------------------
This workstation has two monitors:
  Primary display:    DP-1    (left position,  1920x1080, DisplayPort)
  Secondary display:  HDMI-1  (right position, 1920x1080, HDMI)

Workspace Layout
----------------
  Workspaces 1-5:   assigned to DP-1    (left / primary monitor)
  Workspaces 6-10:  assigned to HDMI-1  (right / secondary monitor)

Multi-Monitor Keybindings
--------------------------
These bindings should be active in the default mode:

  Mod4+Ctrl+>   Move the entire current workspace to the RIGHT output
  Mod4+Ctrl+<   Move the entire current workspace to the LEFT output

  Mod4+Shift+>  Move the focused window/container to the RIGHT output
  Mod4+Shift+<  Move the focused window/container to the LEFT output

  In i3 config, ">" maps to keysym "greater" and "<" maps to keysym "less".
  Workspace movement uses:  move workspace to output <direction>
  Window movement uses:     move container to output <direction>

Auto-Placement Rules (for_window)
-----------------------------------
  WM_CLASS "chromium-no-1"  ->  workspace 1   (DP-1, primary)
  WM_CLASS "chromium-no-2"  ->  workspace 6   (HDMI-1, secondary)

  Criteria in for_window rules must be enclosed in square brackets, e.g.:
    for_window [class="^pattern$"] command
