# Referencia de la API

Este documento proporciona una referencia completa de todos los endpoints de la API disponibles. Cada endpoint incluye su metodo HTTP, patron de URL, parametros requeridos y formato de respuesta.

## URL Base

Todas las solicitudes de API deben realizarse a `https://api.example.com/v2/`. Se requiere autenticacion para todos los endpoints excepto la verificacion de estado.

## Limites de Velocidad

La API aplica limites de 100 solicitudes por minuto por clave de API.
