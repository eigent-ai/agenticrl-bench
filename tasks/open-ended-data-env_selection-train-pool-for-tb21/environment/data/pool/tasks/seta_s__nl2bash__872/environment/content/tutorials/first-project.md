# Your First Project

Learn how to create, configure, and deploy your first project on the platform step by step.

## Create the Project

Log into the dashboard and click "New Project." Choose a name that reflects the project's purpose. Project names must be unique within your organization and can only contain lowercase letters, numbers, and hyphens.

## Configure Settings

Set the project visibility (public or private), choose a default branch name, and configure build settings. The platform auto-detects most frameworks but you can override the build command and output directory.

## Deploy

Push your code to the connected repository. The platform automatically triggers a build and deploys the result to a preview URL. Once verified, promote the preview to production with a single click.
