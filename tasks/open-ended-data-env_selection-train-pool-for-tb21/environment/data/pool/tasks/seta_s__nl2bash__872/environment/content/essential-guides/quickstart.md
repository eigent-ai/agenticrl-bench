# Quickstart Guide

Get up and running in under five minutes with this quickstart guide. We will walk through creating your first project, adding content, and publishing it.

## Step 1: Create a Project

From the dashboard, click "New Project" and choose a template. The blank template gives you full control, while the starter templates include pre-configured layouts and sample content.

## Step 2: Add Content

Use the visual editor to create pages or import existing Markdown files. The editor supports drag-and-drop for images and embedded media.

## Step 3: Publish

Click "Publish" to make your project live. You can configure a custom domain in the project settings. SSL certificates are provisioned automatically.
