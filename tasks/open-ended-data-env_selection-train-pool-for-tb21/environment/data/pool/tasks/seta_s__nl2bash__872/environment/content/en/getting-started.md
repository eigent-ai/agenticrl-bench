# Getting Started

Welcome to the platform documentation. This guide walks you through the initial setup process and helps you get your first project running.

## Prerequisites

Before you begin, make sure you have the following installed on your system:

- Node.js 18 or later
- A package manager (npm or yarn)
- Git version control

## Quick Setup

Clone the starter template and install dependencies. The setup wizard will guide you through the remaining configuration steps. Once complete, you can access the dashboard at localhost:3000.
