# Erste Schritte

Willkommen in der Plattform-Dokumentation. Diese Anleitung fuehrt Sie durch den Einrichtungsprozess und hilft Ihnen, Ihr erstes Projekt zu starten.

## Voraussetzungen

Stellen Sie sicher, dass folgende Software auf Ihrem System installiert ist:

- Node.js 18 oder neuer
- Ein Paketmanager (npm oder yarn)
- Git Versionskontrolle

## Schnelleinrichtung

Klonen Sie die Startvorlage und installieren Sie die Abhaengigkeiten. Der Einrichtungsassistent fuehrt Sie durch die weiteren Schritte.
