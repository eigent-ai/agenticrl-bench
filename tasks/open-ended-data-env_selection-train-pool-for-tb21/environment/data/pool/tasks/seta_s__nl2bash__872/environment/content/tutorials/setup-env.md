# Setting Up Your Development Environment

This tutorial walks through configuring a local development environment for contributing to the platform.

## System Requirements

You need at least 8 GB of RAM, 20 GB of free disk space, and a modern multi-core processor. Development is supported on macOS, Linux, and Windows (via WSL2).

## Install Dependencies

Install the required tools using your system package manager. On macOS, use Homebrew. On Ubuntu, use apt. Ensure you have the correct versions of Node.js, PostgreSQL, and Redis.

## Clone and Configure

Fork the repository, clone your fork locally, and copy the example environment file. Update the database connection string and API keys in your local configuration before starting the development server.
