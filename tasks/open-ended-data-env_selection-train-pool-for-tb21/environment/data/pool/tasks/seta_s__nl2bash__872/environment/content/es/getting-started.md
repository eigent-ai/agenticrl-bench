# Primeros Pasos

Bienvenido a la documentacion de la plataforma. Esta guia le ayudara a realizar la configuracion inicial y a poner en marcha su primer proyecto.

## Requisitos Previos

Antes de comenzar, asegurese de tener instalado lo siguiente en su sistema:

- Node.js 18 o posterior
- Un gestor de paquetes (npm o yarn)
- Control de versiones Git

## Configuracion Rapida

Clone la plantilla de inicio e instale las dependencias. El asistente de configuracion le guiara a traves de los pasos restantes.
