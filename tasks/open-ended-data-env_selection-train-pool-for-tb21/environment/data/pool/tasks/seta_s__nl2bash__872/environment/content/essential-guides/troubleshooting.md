# Troubleshooting Guide

Common issues and their solutions. Check this guide before contacting support.

## Build Failures

If your build fails, check the build logs for specific error messages. Common causes include missing dependencies, syntax errors in configuration files, and insufficient disk space.

## Performance Issues

Slow page loads are often caused by unoptimized images or excessive JavaScript bundles. Use the built-in performance analyzer to identify bottlenecks.

## Connection Problems

If you cannot connect to the platform, verify your network settings, check the status page at status.example.com, and ensure your firewall allows outbound connections on port 443.
