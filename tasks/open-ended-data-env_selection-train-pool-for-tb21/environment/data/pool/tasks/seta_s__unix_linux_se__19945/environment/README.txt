Project README
==============

This project contains a web application with the following structure:

  src/       - Source files (HTML, CSS, PHP)
  config/    - Configuration files
  scripts/   - Automation scripts

To format source files, run:
  ./scripts/format_all.sh

To merge config versions, run:
  ./scripts/merge_configs.sh

Requirements:
  - Vim 8.0+
  - Bash 4.0+
  - Python 3.x (optional, for testing)
