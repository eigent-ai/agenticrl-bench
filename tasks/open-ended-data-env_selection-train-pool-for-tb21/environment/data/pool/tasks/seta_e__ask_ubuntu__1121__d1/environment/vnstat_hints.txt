Useful vnstat commands:
- Install: apt-get install -y vnstat
- Add interface: vnstat --add -i eth0
- List monitored interfaces: vnstat --dbiflist
- One-line monthly stats: vnstat -i eth0 --oneline
  Output format (semicolon-delimited): field 9 = monthly RX, field 10 = monthly TX
- Start daemon: vnstatd -d
- Database location: /var/lib/vnstat/
