3|One JSON object per line over a Unix stream socket. A request is a single line with an

10|             workdir, env, labels]                                     -> id, ...
11|  exec       id, argv, [timeout_s, workdir, env, stdin_b64, stream, binary]
12|                                                                       -> rc, stdout, stderr, timed_out
13|  put_file   id, path, data_b64, [mode]                               (alias: put)
14|  get_file   id, path                                                  -> data_b64 (alias: get)
15|  terminate  id
16|  poll       id                                                        -> running, rc
17|  list       [all]                                                     -> sandboxes
18|  usage                                                                -> budget and counters
19|  policy                                                               -> effective limits
20|  shutdown   [exit]                                                    (admin only)
