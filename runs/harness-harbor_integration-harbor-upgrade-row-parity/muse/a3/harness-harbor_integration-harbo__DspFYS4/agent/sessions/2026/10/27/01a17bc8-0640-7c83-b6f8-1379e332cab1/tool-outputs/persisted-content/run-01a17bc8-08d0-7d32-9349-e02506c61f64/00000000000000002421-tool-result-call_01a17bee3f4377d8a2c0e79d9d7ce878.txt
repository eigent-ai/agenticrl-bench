655|
656|        ``tmux send-keys`` rejects commands above its internal message size

659|        staged into a file inside the environment with base64 chunks
660|        (``environment.exec`` does not go through tmux, so it is not subject

663|        default newline-to-carriage-return conversion makes multi-line
664|        payloads behave as if typed line by line.
665|        """
