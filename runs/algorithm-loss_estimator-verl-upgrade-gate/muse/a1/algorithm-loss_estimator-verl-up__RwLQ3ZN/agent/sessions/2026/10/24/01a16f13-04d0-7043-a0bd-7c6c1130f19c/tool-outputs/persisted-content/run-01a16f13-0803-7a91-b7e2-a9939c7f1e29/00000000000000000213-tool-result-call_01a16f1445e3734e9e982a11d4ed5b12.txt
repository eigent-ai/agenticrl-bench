14|"""
15|Rollout Correction Helper Module
16|
17|This module provides a complete pipeline to address **off-policy issues** in RL training,
18|including:
19|1. Policy mismatch between rollout and training implementations (e.g., vLLM BFloat16 vs FSDP FP32)
20|2. Model update staleness (training on trajectories from older checkpoints)
21|3. General distribution shifts between data collection and training
22|
23|Its core capabilities include computing importance sampling (IS) weights,
24|filtering outlier samples via rejection sampling (RS), and
25|tracking metrics to diagnose and correct off-policy issues.
26|
27|## Core Capabilities
28|1. **Multi-Granularity Aggregation**:
29|   - Importance Sampling (IS):
30|        Token-level
31|        Sequence-level
32|   - Rejection Sampling (RS):
33|        Divergence-based filters (token_k*, seq_sum_k*, seq_mean_k*, seq_max_k*)
34|2. **Memory-Efficient Design**:
35|   - Log-space computations to avoid numerical overflow/underflow.
36|   - Fixed safety bounds (exp(±20)) for stable exponentiation.
37|   - Metrics calculated without large intermediate tensors (prevents CUDA OOM).
38|3. **Comprehensive Metrics Tracking**:
39|   - IS/RS statistics (mean/max/min, effective sample size ESS, rejection rate).
40|   - Off-policy diagnostics (KL divergence, perplexity PPL, log PPL difference, χ² divergence).
41|   - Sequence-level breakdowns (deviation from ideal weights, outlier fraction).
42|
43|## Key Interfaces & Usage
44|- compute_rollout_correction_and_rejection_mask(): compute IS weights + rejection mask.
45|- compute_rollout_correction_weights(): only compute truncated IS weights (for variance
46|  reduction, no outlier rejection).
47|- compute_rollout_rejection_mask(): only filter outliers (for sample cleaning, no IS weight
48|  computation).
49|- compute_offpolicy_metrics(): called by core functions to calculate off-policy diagnostics
50|  (KL/PPL/χ²) — no direct external calls needed.
51|
52|### Integration Notes
53|- Used in `ray_trainer.py` via `compute_rollout_correction_and_add_to_batch()` (batch training pipeline).
54|- Used in `dp_actor.py` for distributed worker computations (distributed training scenarios).
55|- All functions support batch inputs and valid token masking (via `response_mask`).
56|
57|
58|## References
59|- "When Speed Kills Stability: Demystifying RL Collapse from the Training-Inference Mismatch": https://richardli.xyz/rl-collapse
60|- Off-policy RL (theoretical basis for IS): https://fengyao.notion.site/off-policy-rl

93|def _parse_rollout_is_threshold(threshold_spec: str | float) -> tuple[float, Optional[float]]:
94|    if isinstance(threshold_spec, bool):
95|        raise TypeError(
96|            "rollout_is_threshold must be specified as a float or a string threshold specification, not a boolean."
97|        )
98|    if isinstance(threshold_spec, int | float):
99|        upper = float(threshold_spec)
100|        lower = None
101|    elif isinstance(threshold_spec, str):
102|        spec = threshold_spec.strip()
103|        if not spec:
104|            raise ValueError("rollout_is_threshold must not be an empty string.")
105|        if "_" in spec:
106|            lower_str, upper_str = spec.split("_", 1)
107|            try:
108|                lower = float(lower_str)
109|                upper = float(upper_str)
110|            except ValueError as exc:
111|                raise ValueError(f"Invalid rollout_is_threshold '{threshold_spec}'.") from exc
112|        else:
113|            try:
114|                upper = float(spec)
115|            except ValueError as exc:
116|                raise ValueError(f"Invalid rollout_is_threshold '{threshold_spec}'.") from exc
117|            lower = None
118|    else:
119|        raise TypeError("rollout_is_threshold must be a float or a string threshold specification.")
120|
121|    if upper <= 0:
122|        raise ValueError(f"rollout_is_threshold upper bound must be positive, got {upper}.")
123|    if lower is not None:
124|        if lower <= 0:
125|            raise ValueError(f"rollout_is_threshold lower bound must be positive, got {lower}.")
126|        if lower > upper:
127|            raise ValueError("rollout_is_threshold lower bound must be <= upper bound.")
128|
129|    return upper, lower

132|def _parse_rollout_rs_thresholds(
133|    options: list[str], threshold_spec: Optional[str | float]
134|) -> dict[str, dict[str, Optional[float]]]:
135|    if threshold_spec is None:
136|        raise ValueError("rollout_rs_threshold must be provided for rejection sampling.")
137|
138|    if isinstance(threshold_spec, int | float):
139|        raw_specs: list[str] = [str(threshold_spec)]
140|    elif isinstance(threshold_spec, str):
141|        raw_specs = [part.strip() for part in threshold_spec.split(",") if part.strip()]
142|    else:
143|        raise TypeError("rollout_rs_threshold must be a string or numeric value specifying per-option thresholds.")
144|
145|    if not raw_specs:
146|        raise ValueError("rollout_rs_threshold must contain at least one threshold value.")
147|
148|    if len(raw_specs) not in (1, len(options)):
149|        raise ValueError(
150|            f"rollout_rs_threshold expects either one threshold shared by all options or exactly "
151|            f"{len(options)} thresholds to match the provided rollout_rs options."
152|        )
153|
154|    if len(raw_specs) == 1 and len(options) > 1:
155|        raw_specs = raw_specs * len(options)
156|
157|    thresholds: dict[str, dict[str, Optional[float]]] = {}
158|    for option, spec in zip(options, raw_specs, strict=False):
159|        if option.endswith("k1"):
160|            if "_" in spec:
161|                lower_str, upper_str = spec.split("_", 1)
162|            else:
163|                upper_str = spec
164|                lower_str = str(1.0 / float(upper_str))
165|            try:
166|                lower = float(lower_str)
167|                upper = float(upper_str)
168|            except ValueError as exc:
169|                raise ValueError(f"Invalid numeric threshold '{spec}' for option '{option}'.") from exc
170|            if lower <= 0 or upper <= 0:
171|                raise ValueError(f"Thresholds for option '{option}' must be positive, got {spec}.")
172|            if lower > upper:
173|                raise ValueError(f"Thresholds for option '{option}' must be lower <= upper, got {spec}.")
174|            thresholds[option] = {
175|                "lower": lower,
176|                "upper": upper,
177|            }
178|        else:
179|            if "_" in spec:
180|                raise ValueError(
181|                    f"rollout_rs_threshold for option '{option}' must provide a single upper bound "
182|                    f"without '_'. Received '{spec}'."
183|                )
184|            try:
185|                upper = float(spec)
186|            except ValueError as exc:
187|                raise ValueError(f"Invalid numeric threshold '{spec}' for option '{option}'.") from exc
188|            if upper <= 0:
189|                raise ValueError(f"Threshold for option '{option}' must be positive, got {spec}.")
190|            thresholds[option] = {
191|                "lower": None,
192|                "upper": upper,
193|            }
194|    return thresholds

197|def compute_rollout_rejection_mask(
198|    log_ratio: torch.Tensor,
199|    response_mask: torch.Tensor,
200|    rollout_rs: str = "token_k1",
201|    rollout_rs_threshold: Optional[str | float] = None,
202|) -> tuple[torch.Tensor, dict[str, float]]:
203|    """Compute hard trust region mask using divergence estimators.
204|
205|    This function enforces a hard trust region constraint by masking tokens/sequences
206|    where the estimated divergence (between training and rollout policies) exceeds
207|    a threshold. Unlike PPO's soft clipping, this provides a hard boundary.
208|
209|    Multiple rejection criteria can be supplied via a comma separated `rollout_rs` string.
210|    All requested options must pass for a token/sequence to remain valid.
211|
212|    Supported KL divergence-based modes (ideal = 0.0 unless noted):
213|    - "token_k{1,2,3}": Token-level divergences.
214|    - "seq_sum_k{1,2,3}": Sum of token divergences per sequence.
215|    - "seq_mean_k{1,2,3}": Mean of token divergences per sequence.
216|    - "seq_max_k{2,3}": Maximum token divergence per sequence.
217|
218|    Args:
219|        log_ratio: Log ratio of training policy probability to rollout policy probability,
220|            shape (batch_size, seq_length).
221|        response_mask: Binary mask for valid tokens (1=valid, 0=padding),
222|            shape (batch_size, seq_length).
223|        rollout_rs: Comma separated rejection sampling options (e.g. "token_k1,seq_sum_k3").
224|        rollout_rs_threshold: Threshold specification string (required). Provide one entry per
225|            rollout_rs option separated by commas. Each entry must be a positive number.
226|            For K1-style options (``*k1``), specify ``lower_upper`` (e.g. ``"0.1_1.2"``)
227|            to denote lower/upper ratio bounds; other options accept a single upper bound.
228|
229|    Returns:
230|        Tuple containing:
231|            modified_response_mask: Response mask with trust region violations masked (0=rejected),
232|                shape (batch_size, seq_length).
233|            metrics: Dictionary of trust region metrics (all scalars).
234|    """
235|    if rollout_rs is None or not isinstance(rollout_rs, str):
236|        raise ValueError("rollout_rs must be a non-empty string (comma separated for multiple options).")
237|    if rollout_rs_threshold is None:
238|        raise ValueError("rollout_rs_threshold must be provided for rejection sampling.")
239|
240|    if log_ratio.shape[0] == 0:
241|        return response_mask, {}
242|
243|    # rollout_rs supports chained criteria via comma separation (e.g. "token_k1,seq_mean_k3").
244|    #            Every listed option must pass; combined_mask aggregates them via logical AND.
245|    option_modes = [opt.strip() for opt in rollout_rs.split(",") if opt.strip()]
246|    if not option_modes:
247|        raise ValueError("rollout_rs must contain at least one valid option.")
248|
249|    normalized_options: list[str] = []
250|    seen: set[str] = set()
251|    for opt in option_modes:
252|        if opt not in SUPPORTED_ROLLOUT_RS_OPTIONS:
253|            raise ValueError(
254|                f"Invalid rollout_rs option: {opt}. Must be one of {sorted(SUPPORTED_ROLLOUT_RS_OPTIONS)}."
255|            )
256|        if opt not in seen:
257|            normalized_options.append(opt)
258|            seen.add(opt)
259|
260|    threshold_specs = _parse_rollout_rs_thresholds(normalized_options, rollout_rs_threshold)
261|
262|    log_ratio_safe: torch.Tensor = torch.clamp(log_ratio, min=-SAFETY_BOUND, max=SAFETY_BOUND)
263|    token_k1: torch.Tensor = -log_ratio_safe
264|    token_k2: torch.Tensor = 0.5 * log_ratio_safe**2
265|    token_k3: torch.Tensor = torch.exp(log_ratio_safe) - 1.0 - log_ratio_safe
266|
267|    response_mask_bool: torch.Tensor = response_mask.bool()
268|    seq_valid_mask: torch.Tensor = response_mask.sum(dim=-1) > 0
269|    # combined_mask accumulates per-option passes; any failure flips tokens to 0.
270|    combined_mask: torch.Tensor = torch.ones_like(response_mask, dtype=log_ratio.dtype)
271|    metrics: dict[str, float] = {}
272|
273|    def _sequence_sum(values: torch.Tensor) -> torch.Tensor:
274|        return verl_F.masked_sum(values, response_mask, axis=-1)
275|
276|    def _sequence_mean(values: torch.Tensor) -> torch.Tensor:
277|        return verl_F.masked_mean(values, response_mask, axis=-1)
278|
279|    def _sequence_max(values: torch.Tensor) -> torch.Tensor:
280|        mask_bool = response_mask.bool()
281|        neg_inf = torch.tensor(float("-inf"), device=values.device, dtype=values.dtype)
282|        masked_values = values.masked_fill(~mask_bool, neg_inf)
283|        max_values = masked_values.max(dim=-1).values
284|        return torch.where(max_values == neg_inf, torch.zeros_like(max_values), max_values)
285|
286|    for option_name in normalized_options:
287|        thresholds_info = threshold_specs[option_name]
288|        is_k1_option = option_name.endswith("k1")
289|        upper_value = thresholds_info["upper"]
290|        lower_value = thresholds_info["lower"]
291|        apply_lower_threshold = is_k1_option
292|        lower_log: Optional[float] = None
293|        upper_log: Optional[float] = None
294|
295|        if is_k1_option:
296|            if lower_value is None or upper_value is None:
297|                raise ValueError(
298|                    f"rollout_rs_threshold for option '{option_name}' must specify both lower and upper bounds."
299|                )
300|            lower_log = math.log(lower_value)
301|            upper_log = math.log(upper_value)
302|        else:
303|            if upper_value is None:
304|                raise ValueError(f"rollout_rs_threshold for option '{option_name}' must specify an upper bound.")
305|
306|        level = "sequence" if option_name not in TOKEN_LEVEL_ROLLOUT_RS_OPTIONS else "token"
307|
308|        per_token_stat: torch.Tensor
309|        per_sequence_stat: Optional[torch.Tensor] = None
310|        token_keep_bool: torch.Tensor
311|
312|        if option_name == "token_k1":
313|            if lower_log is None:
314|                raise ValueError("Threshold specification for token_k1 must include lower and upper bounds.")
315|            per_token_stat = token_k1
316|            token_keep_bool = (per_token_stat >= lower_log) & (per_token_stat <= upper_log)
317|        elif option_name == "token_k2":
318|            per_token_stat = token_k2
319|            token_keep_bool = per_token_stat <= upper_value
320|        elif option_name == "token_k3":
321|            per_token_stat = token_k3
322|            token_keep_bool = per_token_stat <= upper_value
323|        elif option_name.startswith("seq_sum"):
324|            if option_name.endswith("k1"):
325|                if lower_log is None:
326|                    raise ValueError(
327|                        f"Threshold specification for option '{option_name}' must include lower and upper bounds."
328|                    )
329|                seq_stat = _sequence_sum(token_k1)
330|                seq_keep_bool_direct = (seq_stat >= lower_log) & (seq_stat <= upper_log)
331|            elif option_name.endswith("k2"):
332|                seq_stat = _sequence_sum(token_k2)
333|                seq_keep_bool_direct = seq_stat <= upper_value
334|            elif option_name.endswith("k3"):
335|                seq_stat = _sequence_sum(token_k3)
336|                seq_keep_bool_direct = seq_stat <= upper_value
337|            else:
338|                raise ValueError(f"Unsupported rollout_rs option: {option_name}.")
339|            per_sequence_stat = seq_stat
340|            token_keep_bool = seq_keep_bool_direct.unsqueeze(-1).expand_as(response_mask_bool)
341|            per_token_stat = seq_stat.unsqueeze(-1).expand_as(response_mask)
342|        elif option_name.startswith("seq_mean"):
343|            if option_name.endswith("k1"):
344|                if lower_log is None:
345|                    raise ValueError(
346|                        f"Threshold specification for option '{option_name}' must include lower and upper bounds."
347|                    )
348|                seq_stat = _sequence_mean(token_k1)
349|                seq_keep_bool_direct = (seq_stat >= lower_log) & (seq_stat <= upper_log)
350|            elif option_name.endswith("k2"):
351|                seq_stat = _sequence_mean(token_k2)
352|                seq_keep_bool_direct = seq_stat <= upper_value
353|            elif option_name.endswith("k3"):
354|                seq_stat = _sequence_mean(token_k3)
355|                seq_keep_bool_direct = seq_stat <= upper_value
356|            else:
357|                raise ValueError(f"Unsupported rollout_rs option: {option_name}.")
358|            per_sequence_stat = seq_stat
359|            token_keep_bool = seq_keep_bool_direct.unsqueeze(-1).expand_as(response_mask_bool)
360|            per_token_stat = seq_stat.unsqueeze(-1).expand_as(response_mask)
361|        elif option_name.startswith("seq_max"):
362|            if option_name.endswith("k2"):
363|                seq_stat = _sequence_max(token_k2)
364|                seq_keep_bool_direct = seq_stat <= upper_value
365|            elif option_name.endswith("k3"):
366|                seq_stat = _sequence_max(token_k3)
367|                seq_keep_bool_direct = seq_stat <= upper_value
368|            else:
369|                raise ValueError(f"Unsupported rollout_rs option: {option_name}.")
370|            per_sequence_stat = seq_stat
371|            token_keep_bool = seq_keep_bool_direct.unsqueeze(-1).expand_as(response_mask_bool)
372|            per_token_stat = seq_stat.unsqueeze(-1).expand_as(response_mask)
373|        else:
374|            raise ValueError(f"Unsupported rollout_rs option: {option_name}.")
375|
376|        metrics_upper_threshold = upper_log if is_k1_option else upper_value
377|        metrics_lower_threshold = lower_log if (is_k1_option and lower_log is not None) else 0.0
378|
379|        token_keep_mask = token_keep_bool.to(dtype=log_ratio.dtype)
380|        combined_mask = combined_mask * token_keep_mask
381|        seq_keep_bool_tensor = (~((~token_keep_bool) & response_mask_bool)).all(dim=-1)
382|
383|        option_metrics = compute_rs_metrics(
384|            option_name=option_name,
385|            rs_statistic=per_token_stat,
386|            response_mask=response_mask,
387|            seq_valid_mask=seq_valid_mask,
388|            level=level,
389|            per_sequence_values=per_sequence_stat,
390|            rollout_rs_threshold=metrics_upper_threshold,
391|            rollout_rs_threshold_lower=metrics_lower_threshold,
392|            apply_lower_threshold=apply_lower_threshold,
393|        )
394|        metrics.update(option_metrics)
395|
396|        token_masked_fraction = verl_F.masked_mean(1 - token_keep_mask, response_mask).item()
397|        seq_valid_float = seq_valid_mask.float()
398|        if seq_valid_float.sum() > 0:
399|            seq_keep_float = seq_keep_bool_tensor.to(dtype=log_ratio.dtype)
400|            seq_masked_fraction = (((1.0 - seq_keep_float) * seq_valid_float).sum() / seq_valid_float.sum()).item()
401|        else:
402|            seq_masked_fraction = 0.0
403|        metrics[f"rollout_rs_{option_name}_masked_fraction"] = token_masked_fraction
404|        metrics[f"rollout_rs_{option_name}_seq_masked_fraction"] = seq_masked_fraction
405|
406|    final_mask = combined_mask
407|    metrics["rollout_rs_masked_fraction"] = verl_F.masked_mean(1 - final_mask, response_mask).item()
408|    final_keep_bool = (final_mask > 0.5) & response_mask_bool
409|    seq_has_masked: torch.Tensor = (~final_keep_bool & response_mask_bool).any(dim=-1)
410|    metrics["rollout_rs_seq_masked_fraction"] = seq_has_masked.float().mean().item()
411|
412|    modified_response_mask: torch.Tensor = (response_mask * final_mask).to(dtype=response_mask.dtype)
413|    return modified_response_mask, metrics

416|def compute_rs_metrics(
417|    option_name: str,
418|    rs_statistic: torch.Tensor,
419|    response_mask: torch.Tensor,
420|    seq_valid_mask: torch.Tensor,
421|    *,
422|    level: str,
423|    per_sequence_values: Optional[torch.Tensor],
424|    rollout_rs_threshold: float,
425|    rollout_rs_threshold_lower: float,
426|    apply_lower_threshold: bool,
427|) -> dict[str, float]:
428|    """Compute metrics for hard trust region enforcement (per-option).
429|
430|    Args:
431|        option_name: Original option string supplied by the user.
432|        rs_statistic: Trust region statistic (per token) used for thresholding.
433|        response_mask: Binary mask for valid tokens (1=valid, 0=padding).
434|        seq_valid_mask: Boolean mask indicating sequences with at least one valid token.
435|        level: "token" or "sequence" describing aggregation level.
436|        per_sequence_values: Optional per-sequence statistic (same semantics as rs_statistic).
437|        rollout_rs_threshold: Upper threshold.
438|        rollout_rs_threshold_lower: Lower threshold (ignored if ``apply_lower_threshold`` is False).
439|        apply_lower_threshold: Whether to mask/log metrics for values below the lower threshold.
440|    """
441|    if not response_mask.any():
442|        raise ValueError("response_mask must contain at least one valid token (1).")
443|
444|    metrics: dict[str, float] = {}
445|    prefix = f"rollout_rs_{option_name}"
446|    mask_bool: torch.Tensor = response_mask.bool()
447|
448|    # Compute sequence statistics (used by several metrics).
449|    if per_sequence_values is not None:
450|        seq_values = per_sequence_values
451|    else:
452|        seq_values = verl_F.masked_mean(rs_statistic, response_mask, axis=-1)
453|    if seq_values.dim() > 1:
454|        seq_values = seq_values.squeeze(-1)
455|    seq_values_valid = seq_values[seq_valid_mask]
456|
457|    # Mean of the statistic (always reported).
458|    metrics[f"{prefix}_mean"] = verl_F.masked_mean(rs_statistic, response_mask).item()
459|
460|    # Max/min values.
461|    if level == "sequence" and seq_values_valid.numel() > 0:
462|        metrics[f"{prefix}_max"] = seq_values_valid.max().item()
463|        metrics[f"{prefix}_min"] = seq_values_valid.min().item()
464|    else:
465|        metrics[f"{prefix}_max"] = rs_statistic.masked_fill(~mask_bool, float("-inf")).max().item()
466|        metrics[f"{prefix}_min"] = rs_statistic.masked_fill(~mask_bool, float("inf")).min().item()
467|
468|    # Fractions above/below the thresholds.
469|    if level == "sequence" and seq_values_valid.numel() > 0:
470|        fraction_high = (seq_values_valid > rollout_rs_threshold).float().mean().item()
471|        fraction_low = (
472|            (seq_values_valid < rollout_rs_threshold_lower).float().mean().item() if apply_lower_threshold else 0.0
473|        )
474|    else:
475|        fraction_high = verl_F.masked_mean((rs_statistic > rollout_rs_threshold).float(), response_mask).item()
476|        fraction_low = (
477|            verl_F.masked_mean((rs_statistic < rollout_rs_threshold_lower).float(), response_mask).item()
478|            if apply_lower_threshold
479|            else 0.0
480|        )
481|    metrics[f"{prefix}_fraction_high"] = fraction_high
482|    metrics[f"{prefix}_fraction_low"] = fraction_low
483|
484|    # Standard deviation (clamped for stability).
485|    mask_count: torch.Tensor = response_mask.sum()
486|    if mask_count > 1:
487|        if apply_lower_threshold:
488|            clamp_min = rollout_rs_threshold_lower
489|        else:
490|            clamp_min = 0.0
491|        stat_for_std: torch.Tensor = rs_statistic.clamp(min=clamp_min, max=rollout_rs_threshold)
492|        mean_clamped: torch.Tensor = verl_F.masked_mean(stat_for_std, response_mask)
493|        stat_var: torch.Tensor = verl_F.masked_mean(stat_for_std.square(), response_mask) - mean_clamped.square()
