1|"""Harbor environment backed by the sandbox broker.
2|
3|Use it wherever Harbor would otherwise create Modal sandboxes itself::
4|
5|    EnvironmentConfig(import_path="sandbox_broker.harbor_env:BrokerEnvironment", kwargs={...})
6|
7|or on the command line: ``harbor run --environment-import-path sandbox_broker.harbor_env:BrokerEnvironment``.
8|
9|The task's image comes from ``[environment].docker_image`` when set, otherwise from its
10|``environment/`` build context (the broker only builds contexts on its allowlist). CPU and
11|memory follow the task config and Harbor's overrides. Task containers never have network
12|access, whatever the task's ``network_mode`` says.
13|
14|For code that builds ``EnvironmentConfig(type=...)`` and cannot be changed, call
15|``use_for_modal_environment_type()`` once in the process before trials start.

116|    async def exec(self, command: str, cwd: str | None = None, env: dict[str, str] | None = None,
